Empieza con esta prueba

  1. Abre la caja. Pon 500 de cantidad (gramos) y busca TOMATE.
  2. Selecciona el producto. Debe sumar $1.900.
  3. Escribe $2.000 como efectivo recibido y registra la venta: el cambio es $100.
  4. Vuelve aquí, pulsa Simular sin conexión y registra otra venta.
  5. Verás un pendiente. Pulsa Reconectar: debe llegar al servidor una sola vez.

El tomate comienza con stock 0; venderlo debe dejar el inventario negativo sin bloquearte.
